# Todo

Vanilla JS로 만든 날짜별 할 일 관리 웹 앱입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다. 별도 설치나 빌드는 필요 없습니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 레이아웃 |
| `style.css` | 스타일 |
| `app.js` | 앱 로직 |

## 주요 기능

### Todo CRUD

- 텍스트 입력 후 **추가** 버튼 또는 Enter로 Todo 생성
- 각 항목 **수정** / **완료** / **삭제**
- 빈 값으로는 생성·저장되지 않으며 안내 메시지 표시
- 완료된 Todo는 텍스트에 취소선 표시

### 상태 필터

- **전체** / **진행 중** / **완료** 탭으로 목록 필터링
- 현재 선택된 탭은 시각적으로 구분

### 주간 · 일간 뷰

- 입력창 위 **주간 캘린더**에서 요일(날짜) 선택
- 화살표로 **이전 주** / **다음 주** 이동
- 날짜별 **Todo 개수** 표시 (`N개` / `-`)
- **오늘**, **선택한 날**은 각각 다른 색으로 표시 (오늘이면서 선택된 날은 두 스타일 합침)
- 선택한 날짜에 해당하는 Todo만 목록에 표시
- 새 Todo는 **현재 선택된 날짜**에 저장

### 데이터 저장

- Todo 변경 시 **로컬 스토리지**에 자동 저장
- `JSON.stringify` / `JSON.parse`로 저장·불러오기
- 새로고침 후에도 데이터 유지
